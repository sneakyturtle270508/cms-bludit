# Synapse Bludit Theme

Upload this folder to:

/bl-themes/synapse-bludit-theme/

Required final structure:

/bl-themes/synapse-bludit-theme/index.php
/bl-themes/synapse-bludit-theme/metadata.json
/bl-themes/synapse-bludit-theme/languages/en.json
/bl-themes/synapse-bludit-theme/css/style.css
/bl-themes/synapse-bludit-theme/js/a11y.js

Then activate it in:

Bludit Admin > Themes > Synapse Bludit Theme

Use the Bludit page title for the article title.
Use the Bludit page description for the subtitle.
Write article content in the editor.
